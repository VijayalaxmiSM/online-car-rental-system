# Online Car Rental System 🚗

## About the Project

The **Online Car Rental System** is a web application that allows users to view and book cars online.

It makes car rental easier, faster, and more convenient.

## Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript
* Bootstrap
* SQLite

## Features

### User

* Register
* Login
* View cars
* Search cars
* Book a car
* View my bookings
* Logout

### Admin

* Admin login
* Add cars
* Update cars
* Delete cars
* View users
* View bookings

## How to Run

### 1. Clone the project

```bash
git clone https://github.com/your-username/online-car-rental-system.git
```

### 2. Open the project

```bash
cd online-car-rental-system
```

### 3. Install Flask

```bash
pip install flask
```

### 4. Run the project

```bash
python app.py
```

### 5. Open in browser

```text
http://127.0.0.1:5000
```

## Project Objective

The main objective is to provide a simple online platform where users can **search, select, and book rental cars**.
